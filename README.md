# YouTube Farm

A simple tool to play multiple YouTube videos simultaneously in embedded players.

## Features
- Play multiple YouTube videos at once
- Simple interface
- Auto-play functionality
- Works with most YouTube videos

## How to Use
1. Open `youtube.html` in your browser
2. Paste YouTube links (one per line)
3. Click "LOAD VIDEOS"
4. Videos will start playing automatically
